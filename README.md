Welcome! This is the repository of benchmarking code for Nailpolish. You can see the main repository at [davidsongroup/nailpolish](https://github.com/DavidsonGroup/nailpolish)

**Structure of this codebase**
- data/: processed data used to generate the figures and values used in the paper
- plots/: code to generate the figures used in the paper
- results/: final figures in the paper
- scripts/: preprocessing and benchmarking code

**Note:** all plotting code should be run from the root directory e.g. `Rscript plots/plot_2.R`
